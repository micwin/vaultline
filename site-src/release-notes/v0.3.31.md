# Release Notes v0.3.31

## Changes

- Added `secret copy` and `secret move` with collision-safe defaults and explicit `--force`.
- Added `store unseal --from-secret <store:key>` for cross-store passphrase retrieval.
- Refined Smokey integration so runtime data stays isolated in `SMOKEY_STATE_DIR`.
